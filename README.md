## ✨ Features

### Core Functionality
- **Dashboard** - Real-time overview of inventory metrics
- **Product Management** - Add, edit, and track products
- **Supplier Management** - Maintain supplier database
- **Stock Control** - Record stock IN/OUT movements
- **Reports** - View inventory trends and analytics
- **Role-Based Access** - Different permission levels

### Technical Features
- ✅ PostgreSQL database with proper schema
- ✅ RESTful API endpoints
- ✅ Responsive design (mobile & desktop)
- ✅ TypeScript for type safety
- ✅ Next.js 16 with App Router
- ✅ Tailwind CSS for styling
- ✅ Authentication system
- ✅ Role-based access control

## 📋 Prerequisites

Before you begin, ensure you have installed:

- **Node.js** 18.x or higher
- **PostgreSQL** 14.x or higher
- **npm** or **pnpm** (included with Node.js)
- **pgAdmin** (optional, for database management)
