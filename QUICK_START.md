## Features

- **Dashboard** - View inventory overview with stock levels
- **Products** - Manage products catalog
- **Suppliers** - Manage supplier information
- **Stock In/Out** - Record inventory movements
- **Reports** - View analytics and inventory trends

## How to Use

1. Go to the home page
2. Enter any of the email/password combinations above
3. Click "Sign In"
4. You'll be redirected to the Dashboard
5. Use the sidebar to navigate between sections
6. Click "Logout" in the sidebar to log out

## No Database Setup Required

This is a demo version that uses mock data. No PostgreSQL or database setup is needed to run the app.

## Installation & Deployment

1. Download the project code
2. Run `npm install`
3. Run `npm run dev` to start locally
4. Or deploy directly to Vercel using the "Publish" button

Enjoy!
